## Коротко о себе

Небольшая студия: делаю сайты для небольших бизнесов и приложения на Electron —
от идеи и структуры до вёрстки, анимаций и проверки каждой строки.
Всё начиналось с Minecraft: из этого вырос лаунчер, а из него — остальные инструменты.

<div align="center">

| Сайты | Приложения | Minecraft |
|---|---|---|
| лендинги для кофеен, барбершопов, репетиторов | лаунчер, редактор пиксель-арта | сборки, моды, серверы |

## Из крупных проектов

**Kubik Launcher** — лаунчер Minecraft для Windows. Java подбирается сама,
Forge/Fabric/NeoForge, каждая сборка в отдельной папке со своей обложкой,
поиск и установка контента в один клик, друзья по коду и чат.
Скачать: [релизы](https://github.com/NAME-studio/kubik-launcher/releases/latest) · [сайт](https://name-studio.github.io/kubik-launcher/)
